# Local Support AI

Local Support AI - desktop-приложение для Windows, которое помогает сотруднику поддержки быстро подготовить ответ клиенту по тексту и скриншоту переписки. Приложение работает offline-first: не использует cloud API, не содержит телеметрии и делает HTTP-запросы только к локальному Ollama на `localhost`.

## Возможности

- PyQt6 dark UI для ежедневной работы.
- Ввод текста клиента, загрузка скриншота, drag & drop, вставка скриншота через `Ctrl+V`.
- Локальный OCR через EasyOCR по умолчанию, опционально PaddleOCR.
- Локальная генерация ответа через Ollama localhost API.
- Поддержка vision-моделей `qwen2.5vl`, `llava`, `minicpm-v`.
- Автоопределение установленных моделей Ollama через `/api/tags`.
- Система `Мой стиль общения`: несколько стилей, обучение по примерам, импорт/экспорт txt/json, локальное SQLite-хранилище.
- Rule-based анализ обращения: темы, признаки, суммы, даты и MCC-коды через регулярные выражения.
- Тематика также расширяется из активного стиля: сохранённые пользователем ответы пополняют локальный словарь доменных терминов.
- Локальная аналитика: количество сгенерированных ответов, частые темы и последние признаки.
- Индикаторы: локальный режим, OCR, модель.
- Опции: поверх всех окон, компактный режим, полное отключение сетевого доступа.
- Горячие клавиши: `Ctrl+O`, `Ctrl+V`, `Ctrl+Enter`, `Ctrl+Shift+C`, `Ctrl+K`, `Ctrl+,`.

## Установка для разработки

Требуется Python 3.12+.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python .\main.py
```

Если нужен PaddleOCR вместо EasyOCR:

```powershell
python -m pip install -r requirements-optional-paddle.txt
```

Затем выберите `paddleocr` в настройках приложения.

## Локальные OCR-модели

EasyOCR в приложении запускается с `download_enabled=False`, чтобы приложение не скачивало модели само. Первый запуск OCR будет успешным только если модели уже есть локально в кэше EasyOCR. Для полностью оффлайн-сценария подготовьте модели заранее на машине с доступом в интернет или перенесите кэш в пользовательский профиль Windows.

Подготовить EasyOCR-модели на текущем компьютере можно так:

```powershell
.\scripts\prepare_easyocr_models.ps1
```

Или напрямую:

```powershell
python -c "import easyocr; easyocr.Reader(['ru','en'], gpu=False, verbose=True, download_enabled=True)"
```

Модели сохраняются здесь:

```text
%USERPROFILE%\.EasyOCR\model
```

После этого интернет можно отключить: приложение будет использовать уже скачанные OCR-файлы локально.

Если установлена vision-модель Ollama, например `qwen2.5vl`, OCR не обязателен для генерации: можно загрузить скриншот и сразу нажать `Сгенерировать ответ`. В этом режиме изображение уйдет только в локальный Ollama на `localhost`.

## Установка Ollama

1. Установите Ollama для Windows с официального сайта: <https://ollama.com/download/windows>
2. Запустите Ollama. По умолчанию локальный API доступен на:

```text
http://localhost:11434
```

3. Проверьте, что Ollama отвечает:

```powershell
ollama list
```

## Как скачать vision-модель

Рекомендуемая модель:

```powershell
ollama pull qwen2.5vl
```

Альтернативы:

```powershell
ollama pull llava
ollama pull minicpm-v
```

После установки нажмите `Обновить` в верхней панели приложения.

## Приватность

В коде используется два уровня защиты:

- `LocalOnlySession` блокирует HTTP-запросы не к `localhost`, `127.0.0.1` или `::1`.
- `privacy_guard.py` ставит process-level guard на Python-сокеты и блокирует случайные сетевые подключения из зависимостей.

В настройках есть режим `Полностью отключить сетевой доступ`; в этом режиме приложение не обращается даже к локальному Ollama.

Приложение не содержит:

- telemetry;
- analytics;
- cloud inference;
- внешних API;
- фоновых сетевых запросов.

Локальные данные хранятся в:

```text
%LOCALAPPDATA%\Local Support AI
```

## Сборка Windows .exe

Быстрая сборка:

```powershell
.\scripts\build_exe.ps1 -Clean
```

Команда PyInstaller напрямую:


## Использование

1. Запустите Ollama и установите vision-модель.
2. Откройте Local Support AI.
3. Вставьте текст клиента или скриншот.
4. Нажмите `Анализировать`, чтобы извлечь текст OCR.
5. Нажмите `Сгенерировать ответ`.
6. Проверьте текст и нажмите `Копировать`.

## Мой стиль общения

Откройте `Настройки -> Мой стиль общения`.

Можно:

- вставить реальные ответы клиентам;
- создать несколько стилей;
- импортировать `.txt` или `.json`;
- экспортировать стиль;
- нажать `Обучить стиль`;
- выбрать активный стиль.

Анализируются длина сообщений, тон, эмоциональность, дружелюбность, формальность, структура и типичные фразы. Примеры и профиль стиля хранятся локально в SQLite.

## Улучшение стиля по вашим правкам

После генерации можно отредактировать ответ прямо в поле `Сгенерированный ответ` и нажать `Сохранить в стиль`. Приложение добавит финальную версию ответа в активный стиль и пересчитает профиль. Это локальная петля улучшения: следующие ответы будут ближе к вашим реальным правкам без cloud API и без fine-tuning внешней модели.

При пересчёте стиля приложение также выделяет доменные термины из ваших ответов. Если в будущем обращении встречается термин из активного стиля, анализатор может определить тему как `Тема из стиля: ...` даже без заранее прошитого правила.

## Аналитика обращений

Приложение локально анализирует обращение до и после генерации:

- определяет тему обращения: проценты, арест, возврат, премиум, кэшбэк, СБП/MCC, кредит, просрочка;
- выделяет признаки: непонимание правила, риск недовольства, запрос срока/статуса, финансовая операция;
- извлекает суммы, даты и MCC-коды регулярными выражениями;
- сохраняет тему и признаки в SQLite вместе с историей генерации.

В настройках есть вкладка `Аналитика`, где видно:

- сколько ответов уже сгенерировано;
- какие темы встречаются чаще;
- какие признаки были в последних обращениях.
