Настройки содержат две вкладки:

- `Основное`: Ollama localhost URL, модель, OCR engine, поверх всех окон, компактный режим, полное отключение сети.
- `Мой стиль общения`: список стилей, импорт/экспорт txt/json, поле примеров, кнопка `Обучить стиль`, профиль тона.
